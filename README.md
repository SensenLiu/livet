# Life Crutch（暂定中文：「在场」/「Moment」）

> 让 AI 像一根拐杖一样伴随每个人一生 — 真正实现 AI 平权。

## 这是什么

一款多场景"重要时刻 AI 智囊"通用 App，遵守一条产品哲学铁律：

> **「让你不必再向 AI 解释你自己。」**

派生 4 条准则：
1. AI 主动获取上下文，用户只说"当下"
2. 被动提示，不期待回应
3. 数据本地优先，永不保留原声
4. 场景识别渐进自动化（V1 用户选 → V3 全自动）

## 核心战略 30 秒速览

- **战略路径**：路径 C — 平台化 + 先切高付费 vertical（不直接做适老化，但为最终的 AI 平权使命留口子）
- **MVP**：App + 通用蓝牙耳机，¥8-12 万 + 3 个月可起步
- **产品形态**：三种交互模式（🟢主动询问 / 🟡被动提示 / 🔴守护监听）
- **首批场景包**：S1 看病 / S2 谈话 / S5 情绪 / S8 日复盘（覆盖中老年/职场/通用）
- **架构**：端为主 + 极薄 BFF 网关（~200 行）
- **GTM**：7 组场景化短视频，不做通用叙事
- **品牌承诺**：永不保留原声、数据本地优先、不用用户数据训练大模型
